# slope-tools

滑坡稳定性 Demo（A.1）前端脚手架。几何、计算与界面在后续任务中实现。

## 脚本

- `npm run dev`：启动开发服务器
- `npm run build`：类型检查并构建单文件 `dist/index.html`
- `npm run preview`：预览构建结果
- `npm test`：运行 Vitest（`vitest run`）
- `npm run test:watch`：监听模式运行 Vitest

## 技术栈

React、TypeScript、Vite、Ant Design、Vitest、vite-plugin-singlefile。

设计与实现计划见 `docs/superpowers/specs/` 与 `docs/superpowers/plans/`。
