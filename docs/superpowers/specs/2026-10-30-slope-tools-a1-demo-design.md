# slope-tools 第一版设计说明（A.1 Demo）

日期：2026-10-30  
依据：GB/T 38509-2020 附录 A.1 不平衡推力传递法（折线滑面）

## 1. 目标

做一个可在浏览器打开的滑坡稳定性 Demo：可拖折线、实时计算条块参数与稳定系数 \(F_s\)，最终可打包为**单个 HTML**交付。无后端。

第一版只实现附录 **A.1**；A.2 三维楔体法不做。

## 2. 技术栈

| 项 | 选择 |
| --- | --- |
| 开发 | React + Vite + Ant Design |
| 计算 | 浏览器内 TypeScript 模块 |
| 发布 | `vite-plugin-singlefile`（或等价方案）打成单 HTML |

## 3. 界面布局

- **中/左画布**：地面折线 + 滑面折线均可拖拽顶点；在地面与滑面之间自动竖向条分并显示条块。
- **右侧参数**：整坡统一 \(c\)、\(\varphi\)、\(\gamma\)；地震力、孔隙水压力开关（默认关闭，对应力为 0）。
- **下方成果表**：各条块量 + 整坡 \(F_s\)；拖点后即时重算。

## 4. 几何

- 地面、滑面均为可编辑折线；地面带默认示例坡面。
- 条块由地面与滑面几何自动生成（竖向切条）。
- 非法几何（自交、滑面高于地面、空条块等）时提示，不输出 \(F_s\)。

## 5. 计算（A.1–A.5）

按规范公式实现 \(F_s\)、\(R_i\)、\(T_i\)、\(\Psi_i\)、\(E_i\)。

- \(\Psi\) 含 \(F_s\) → **隐式迭代**求解 \(F_s\)。
- 地震/水压力开关关闭时：\(Q_i=V_i=U_{bi}=0\)；外力 \(P_i\) 第一版固定为 0。
- \(F_s\) 不收敛时标红警告。

## 6. 成果表与验证导出

### 6.1 条块表列（第一版）

条块号、\(\alpha_i\)、底面宽 \(b_i\)（或滑面长）、\(W_i\)、\(R_i\)、\(T_i\)、\(\Psi_i\)、\(E_i\)，以及整坡 \(F_s\)。

### 6.2 顶点坐标（验证用）

导出/复制：

- 地面折线顶点 \((x,y)\)
- 滑面折线顶点 \((x,y)\)

可选：条块表 CSV。用途：粘贴到用户已有 Excel 公式表，交叉核对 \(F_s\) 与关键条块量。

正式 Excel / CAD 导出留到后续版本。

## 7. 第一版不做

- 正式 Excel、CAD 导出
- 附录 A.2
- 分条块不同 \(c/\varphi/\gamma\)
- 完整降雨渗流建模（仅保留 \(U_{bi}\) 开关占位）

## 8. 模块划分

- `geometry`：折线、条分
- `calc/a1`：公式与迭代
- `ui/canvas`、`ui/params`、`ui/results`
- `export/coords`：顶点与可选条块表导出

## 9. 验证

- 传递系数求解器单元测试（固定手算算例）
- 人工：顶点坐标 → 用户 Excel → 对比 \(F_s\) 与关键量

## 10. 成功标准

- 本地 `npm run build` 产出可双击打开的单 HTML
- 拖动折线可实时看到条块表与 \(F_s\)
- 可导出顶点坐标用于 Excel 对算
